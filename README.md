# Quantum Threat Timeline

A living, evidence-led tracker of the post-quantum cryptography threat timeline and what it means for migration planning.

The site distinguishes measured hardware results, resource estimates, expert opinion, vendor roadmaps, and policy/standards so that different evidence types are not conflated.

## Publication

The public site is served with GitHub Pages directly from `index.html` on the `main` branch.

## Evidence policy

- Prefer primary sources: standards bodies, government publications, original research papers, and vendor technical material for vendor claims.
- Use independent scientific scrutiny where a claim is contested.
- Distinguish what a source states from analysis or inference.
- Do not present resource estimates as demonstrated attacks.
- Re-check fast-changing policy, standards, and hardware claims before major briefings.
